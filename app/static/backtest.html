Backtesting

Historical replay of the recommendation engine — technical signals only (no live sentiment).

ℹ What is this page for?
This is a strategy validation tool — it replays the recommendation engine on historical data to answer questions like: "Does a higher confidence score actually lead to more profitable trades?" or "Does moderate vs aggressive risk tier perform better?"

Runs on all 28 tracked symbols over a custom date range. It takes ~2–5 minutes to complete.
For a quick analysis of a specific trade you have open, use the Active Trades page — each card has a Backtest button that runs a focused analysis on that symbol.
