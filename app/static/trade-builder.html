“Refresh news & analysis” — need it or not?
  • Not on today’s recommendation list? That alone is not a reason to enable the refresh. Off-list symbols still build from live data; the list only means that asset wasn’t in the last batch ranking.
  • Leave the box off (usual case): Fast. Uses whatever analysis is already in the database plus current prices.
  • Turn it on only if: You want to pull new headlines and re-run the analysis job before this build (can take several minutes; it refreshes the global feed, not only your symbol). Examples: you haven’t run the pipeline yet, or your stored analysis is clearly outdated.
  • Neither option regenerates the full daily recommendations list — use Dashboard → Run full pipeline when you want that.
