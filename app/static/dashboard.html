Workflow & batch notes
  1. Run pipeline (or wait for schedule) → feeds, analysis, today’s recommendations.
  2. Open Market analysis, then Recommendations; mark each row Took it or Skipped.
  3. Active trades shows what you took; refresh that page to see SL/TP updates (every 2h).

Refresh = new set of recs; Clear = remove pending/skipped only. Taken trades persist.
